Konfigurasi Endpoint API

Hubungkan GitHub Pages dengan Google Apps Script (GAS)

Dengan menaruh tampilan ini di GitHub Pages, domain aplikasi sekolah Anda bersifat tetap. Saat kode GAS diperbarui, cukup tempelkan URL Web App GAS di bawah ini.

Saat URL dikosongkan, aplikasi berjalan dalam Mode Database Lokal (tersimpan di browser) untuk demonstrasi penuh.

Panduan Cepat Implementasi di SMP DAFI

  1. Buat Google Sheets Baru: Buka Google Drive akun sekolah, buat Google Spreadsheet baru dengan nama Database DDMS SMP DAFI.
  2. Pasang Kode GAS: Klik menu Ekstensi > Apps Script, hapus kode bawaan, lalu tempel seluruh kode Code.gs di samping.
  3. Inisialisasi Otomatis: Pilih fungsi setupDatabase di toolbar atas lalu klik Jalankan (Run). Script otomatis membuat 4 sheet (Documents, VersionHistory, Users, SuggestedDocs) serta folder Google Drive Arsip_PDF_SMP_DAFI.
  4. Deploy sebagai Web App: Klik Terapkan > Deployment baru, pilih jenis Aplikasi Web, atur Execute as: Me dan Who has access: Anyone. Salin URL /exec yang muncul.
  5. Hosting Domain Tetap di GitHub Pages: Buat repositori GitHub (mis. ddms-smp-dafi), unggah file index.html ini, lalu aktifkan Settings > Pages pada branch main.
Keunggulan Arsitektur Ini:

Menggunakan Content-Type: text/plain;charset=utf-8 pada request fetch() POST ke GAS sehingga pengiriman PDF Base64 dari domain GitHub Pages tidak pernah terblokir oleh aturan CORS browser.
