Konfigurasi Endpoint Cloud

Hubungkan GitHub Pages dengan Google Apps Script (GAS)

Domain GitHub Pages Anda bersifat tetap. Saat script GAS diperbarui, cukup tempelkan URL Web App GAS di bawah ini.

Saat URL dikosongkan, aplikasi berjalan dalam Mode Database Lokal (tersimpan di browser) untuk demonstrasi penuh.

Langkah Pemasangan DDMS SMP DAFI

  1. Buat Google Sheets: Beri nama Database DDMS SMP DAFI.
  2. Pasang Kode GAS: Buka Ekstensi > Apps Script, lalu tempel kode Code.gs di samping.
  3. Inisialisasi: Jalankan fungsi setupDatabase sekali dari editor Apps Script.
  4. Deploy Web App: Pilih Terapkan > Deployment baru > Aplikasi Web (Execute as: Me, Who has access: Anyone).
  5. GitHub Pages: Unggah file index.html ke repositori ddms-smp-dafi.
