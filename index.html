Tempelkan URL Web App Google Apps Script untuk menghubungkan antarmuka ke pangkalan data cloud.

Saat URL dikosongkan, aplikasi berjalan dalam Mode Database Lokal (tersimpan di browser) untuk demonstrasi penuh.
Pindai Folder Drive

Sinkronisasi Massal Folder Drive

Pindai seluruh berkas arsip (PDF, Word .doc / .docx, dan Google Docs) pada folder Drive (Arsip_PDF_SMP_DAFI) untuk mencatatnya otomatis ke dalam katalog dokumen.

Langkah Pemasangan eArchive SMP DAFI

  1. Buat Google Sheets: Beri nama Database DDMS SMP DAFI.
  2. Pasang Kode GAS: Buka Ekstensi > Apps Script, lalu tempel kode Code.gs di samping.
  3. Inisialisasi: Jalankan fungsi setupDatabase sekali dari editor Apps Script.
  4. Deploy Web App: Pilih Terapkan > Deployment baru > Aplikasi Web (Execute as: Me, Who has access: Anyone), lalu salin URL Web App yang berakhiran /exec.
  5. Hubungkan ke Antarmuka: Tempelkan URL Web App pada kolom di atas lalu klik Simpan & Sinkronkan.
